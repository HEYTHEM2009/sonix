# Demo Video Script — Sonix

A 90–120 second walkthrough for the marketplace listing / landing page.

**0:00–0:10 — Hook**
- Opening shot: Sonix logo + tagline "Ship your social app this week."
- Fast cuts: Reels feed, Stories ring, Chat bubbles.

**0:10–0:25 — Onboarding & Auth**
- Show onboarding carousel (5 swipeable pages).
- Login screen → demonstrate 2FA code entry → app home.
- (Voiceover: "Secure by default — 2FA and email verification built in.")

**0:25–0:45 — Feed & Posts**
- Home feed scroll; like animation; open a post; add a comment with @mention.
- Tap "share" → share-to-Sonix picker.
- (Voiceover: "Posts, likes, comments, bookmarks, hashtags — all wired.")

**0:45–1:05 — Reels**
- Open Reels (For You). Double-tap to like. Open creator analytics.
- Show Pro: save as draft / schedule.
- (Voiceover: "Vertical Reels with a For-You engine and creator analytics.")

**1:05–1:25 — Stories & Chat**
- Stories ring → view a story → react.
- Open 1:1 chat: send a message, show typing indicator + delivered/read ticks.
- Open group chat: live message appears.
- (Voiceover: "Real-time chat with presence, typing, and read receipts — plus group chat.")

**1:25–1:40 — Search & Discovery**
- Search tab: type a term → users + hashtags + audio results.
- Open a hashtag feed.

**1:40–1:55 — Admin & Settings**
- Settings → Pro toggle, language switch to Arabic (RTL flips instantly).
- Login as admin → Admin dashboard stats, ban a user, resolve a report.

**1:55–2:10 — Deploy & Close**
- Quick terminal montage: `composer install`, `php artisan migrate --seed`, `npx expo start`.
- Text overlay: "Backend + Mobile + Admin. Docker & EAS ready."
- End card: Sonix logo + "Get it today."

**Tips**
- Capture on a real device (or simulator) at 1080×1920, 30fps.
- Use the demo accounts from `docs/INSTALL.md`.
- Keep on-screen text minimal; rely on voiceover.
