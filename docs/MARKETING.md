## Short description (≤160 chars)

## Long description
Sonix is a production-ready, full-stack social networking starter kit that ships with a Laravel REST API,
a React Native / Expo mobile app (iOS + Android), and a complete admin & moderation panel.

Build the next Reels-first social app without reinventing the wheel. Sonix includes short-video Reels with a
For-You recommendation engine and creator analytics, ephemeral Stories with highlights, real-time 1:1 and group
chat with typing indicators, presence, and read receipts, plus feeds, hashtag discovery, search, notifications,
and a full moderation toolkit. Security is baked in: 2FA, email verification, admin authorization, rate limiting,
signed media URLs, and a pre-sale audit that closed every Critical and High defect.

Rebrand it, deploy it with Docker or your favorite host, and publish to the App Store and Google Play via Expo EAS.
Everything is documented — installation, API, database, deployment, and a buyer guide.
