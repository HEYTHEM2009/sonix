## 2. Long description (paste-ready)
Sonix is a complete, original social-media platform built with **Laravel** (REST API) and
**React Native / Expo** (cross-platform mobile app). It is designed as a **commercial starter
kit**: buy it once, rebrand it, and ship your own Instagram/TikTok-style app — or resell it
as part of your own offering.

### Highlights
- ⚡ **Reels v2 (Pro)**: vertical feed, like/comment/save/share, watch-history analytics,
  trending & For-You ranking, **drafts**, **scheduled publishing**, **featured/curated** feed,
  and a built-in **music library**.
- 🔍 **Global Search**: users, reels, posts, stories, hashtags, and audio with smart suggestions.
- 🛡️ **Admin & Moderation**: dashboard stats, ban/unban users, remove content, resolve reports,
  bad-word filter, and broadcast notifications.
- 👋 **Onboarding**: swipeable first-launch carousel (EN/AR, RTL-ready).
- 💬 **Real-time Chat**: 1:1 + group messaging, typing indicators, read receipts.
- 🔐 **Production-hardened**: rate limiting, security headers, anti-scraping, signed media,
  safe error handling, audit logging, 2FA-ready.
- 🎨 **Rebrand-ready**: original logo, documented brand system, light/dark, RTL (Arabic) support.

### Tech stack
Laravel 11 · Sanctum · PostgreSQL/MySQL · React Native · Expo (EAS) · Expo Router ·
Expo Video · NativeWind/StyleSheet · Free to self-host (Neon, Supabase, Cloudinary Free, MinIO).
